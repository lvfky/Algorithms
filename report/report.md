# Исследование HyperLogLog для оценки числа уникальных элементов в потоке

## 1. Инфраструктура (Этап 1)

### 1.1 RandomStreamGen
Генератор потоков создаёт строки длиной 1–30 из алфавита: `a-zA-Z0-9-`. Генерация детерминирована параметром `seed`. Для моделирования момента времени $t$ поток разбивается на `steps=20` равных частей по длине (префиксы).

### 1.2 HashFuncGen
Хеширование реализовано на базе FNV-1a 64-bit с дополнительным смешиванием (mixing). Для стандартного HLL используется 32-bit значение (диапазон $[0,2^{32})$), для улучшенной версии — 64-bit хеш.

Проверка равномерности: распределение хеша по 1024 корзинам по старшим битам (`plots/hash_uniformity.png`). Дополнительно сохраняется `data/hash_bins.csv`.

## 2. Стандартный HyperLogLog (Этап 2)

Пусть $m=2^B$ регистров, $B=14$, значит $m=16384$. Для каждого элемента вычисляется хеш $x$:
- индекс регистра: первые $B$ бит,
- значение регистра: $\rho(w)$ (позиция первой единицы в оставшихся битах + 1),
- обновление: $M[j]=\max(M[j],\rho(w))$.

Оценка мощности множества:
\[
E = \alpha_m \frac{m^2}{\sum_{j=1}^m 2^{-M[j]}}
\]
Использованы стандартные коррекции small-range (linear counting) и large-range.

Теоретический порядок относительной ошибки (RSE):
\[
\frac{1.04}{\sqrt{m}}=0.008125, \quad \frac{1.32}{\sqrt{m}}=0.010313
\]

## 3. Эмпирические результаты (Этап 3)

Параметры эксперимента:
- потоков: `streams=20`,
- длина потока: `N=200000`,
- шагов: `steps=20`.

На каждом шаге считались:
- точное $F_t^0$ (через `unordered_set`),
- оценка $N_t$ (HLL).

Графики (standard):
- сравнение $F_t^0$ и $N_t$: `plots/plot_compare_standard.png`,
- статистики $E(N_t) \pm \sigma$: `plots/plot_stats_standard.png`,
- относительная ошибка: `plots/plot_relerr_standard.png`.

Данные: `data/raw_runs.csv`, агрегаты: `data/summary_standard.csv`.

## 4. Сравнение с теорией и анализ (Этап 4)

Теоретически ожидаемый масштаб стандартного отклонения порядка
\[
\sigma_{theory}(t) \approx \text{RSE} \cdot F_t^0
\]
и RSE убывает как $1/\sqrt{m}$.

Агрегированные метрики по шагам (стандартная версия):
- MARE = mean(|rel_err|): **0.002063**
- mean σ(rel_err): **0.007540**

Наблюдаемая дисперсия находится того же порядка, что и оценка по $1/\sqrt{m}$; small-range коррекция заметно влияет на первых шагах, когда доля нулевых регистров велика.

## 5. Улучшенная версия HyperLogLog (Этап 5)

### 5.1 Модификация
Реализована улучшенная версия:
- 64-bit хеширование,
- sparse-представление регистров на ранней стадии (unordered_map idx→value) с переходом в dense-вектор при росте числа ненулевых регистров.

### 5.2 Результаты
